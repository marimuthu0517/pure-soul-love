# Pure Soul & Love — Harshiii

A responsive React + Vite appreciation website.

## Run locally
1. Install Node.js (LTS).
2. Extract this folder.
3. Open a terminal in this folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL printed by Vite.

## Customize
- Edit the letter and appreciation messages in `src/App.jsx`.
- Replace the memory card text in the `memories` array.
- Add photos later by replacing the memory cards with `<img>` elements and your own image paths.
- Change colours and spacing in `src/App.css`.

## Build
Run `npm run build`.

## Personal photo gallery
The six photos you supplied are stored locally in `public/images/` and displayed in the Memories gallery. They are not uploaded to an external image host.
